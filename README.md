# Cooked Dev social stats

Public statistics for the Cooked Dev accounts on Instagram, TikTok, YouTube, X and Facebook. The public dashboard is hosted with Sites. GitHub Actions refreshes public metrics hourly at minute 17 UTC, independently of the owner's computer. GitHub may delay scheduled jobs.

`data/latest.json` holds public observations with a source and timestamp for every metric. `data/posts.csv` and `data/platforms.csv` feed Google Sheets. Failed collection preserves earlier observations and updates the source status; it never fabricates a zero or advances a metric's observation time. Platform view counts are additive plays, not unique cross-platform reach.

Run `python scripts/collect.py` to refresh. Python 3.12 and yt-dlp are required for collection. `python scripts/test_data.py` validates the snapshot. Public pages can withhold metrics or block server requests. Authenticated owner tables can supply additional observations through the bulk browser workflow below; missing values and blocked sessions retain their prior timestamps. The initial registry contained 12 verified videos. New TikTok records are adopted only with an observed owner-matched identity. Existing public posts are refreshed separately.

The owner also uses a bulk browser capture through the already connected Lost Chrome profile. Instagram reel grids and TikTok Studio / Facebook content tables are read together, without opening every video or creating developer apps. Normalized public measurements merge into the same snapshot; rounded labels retain `approximate: true`. The browser-assisted pass requires the owner's computer and extension to be available; the GitHub collector remains independent. Private analytics exports, cookies and account tokens are never included here. The registry now contains 13 videos and 25 verified IG/TikTok publications; the newest TikTok upload has no guessed Drive or Instagram match.
