# Cooked Dev social stats

Public statistics for Cooked Dev and Indian Builds. Cooked Dev uses Instagram, TikTok, YouTube, X and Facebook; Indian Builds currently uses Instagram, TikTok, Facebook and X. The public dashboard is hosted with Sites. GitHub Actions checks public sources hourly at minute 17 UTC, independently of the owner's computer. GitHub may delay scheduled jobs, and public sources can withhold metrics.

`data/latest.json` holds public observations with a source and timestamp for every metric. `data/posts.csv` and `data/platforms.csv` feed Google Sheets. Failed collection preserves earlier observations and updates the source status; it never fabricates a zero or advances a metric's observation time. Platform view counts are additive plays, not unique cross-platform reach.

Run `python scripts/collect.py` to refresh. Python 3.12 and yt-dlp are required for collection. `python scripts/test_data.py` validates the snapshot. Public pages can withhold metrics or block server requests. Authenticated owner tables can supply additional observations through the bulk browser workflow below; missing values and blocked sessions retain their prior timestamps. The initial registry contained 12 verified videos. New TikTok records are adopted only with an observed owner-matched identity. Existing public posts are refreshed separately.

The owner also uses a bulk browser capture through the already connected Lost Chrome profile. Instagram reel grids and TikTok Studio / Facebook content tables are read together, without opening every video or creating developer apps. Normalized public measurements merge into the correct channel snapshot; rounded labels retain `approximate: true`. The browser-assisted pass requires the owner's computer and extension to be available; the GitHub collector remains independent. Private analytics exports, cookies and account tokens are never included here.

## Indian Builds

`data/channels.json` maps each channel to its own feed. Indian Builds uses `data/indian-builds/latest.json`, `posts.csv`, `platforms.csv` and `archive/`. Its exact identities are Instagram `indiaanbuilds`, TikTok `indiaanbuilds`, Facebook `https://www.facebook.com/profile.php?id=61594164374065`, and X `https://x.com/IndiaanBuilds`. This Facebook Page is distinct from Cooked Dev's `61595564490107`; Indian Builds X `IndiaanBuilds` is distinct from Cooked Dev X `Cooked_Deev`. A home-feed URL never identifies a channel; use the verified profile URL. Drive originals come only from folder `1WEHFKQCzbjUcPzm7nYB3PthPngxLXYGR`; an individual file is linked only after a verified content match. Folder registration does not imply that its inventory has been verified.

Tracking began on 20 October 2026. Existing White Hack content is excluded by observed publication IDs and, for automatic TikTok discovery, by publication time. Account followers are tracked normally; account-wide likes are distinct from likes on tracked videos. The source retains the previous observation date when a request fails. `trackedEmptyConfirmedAt` confirms zero videos within the new content scope, not an empty legacy account.

`python scripts/collect_channels.py` checks additional channels independently of the Cooked Dev collector. `--export-only` exports an existing feed without fetching sources. `python scripts/test_channels.py` verifies separation, ownership, legacy exclusions and unknown-value preservation.

For authorized Lost Chrome bulk captures use `python scripts/import_channel_capture.py --input <private-capture.json> --dashboard data/indian-builds/latest.json`. The capture requires `channelId: "indian-builds"` and a `platforms` object. Each platform supplies `browserProfile: "lostastronaut.space"`, exact `accountUrl`, actual UTC `observedAt`, optional `profileMetrics`, and `posts` with actual `id`, `url` and visible `metrics`. New publications additionally require `public: true`, `caption`, and a verified date when available. Set `completeList: true` only after checking the whole list; `status: "unavailable"` preserves all earlier metrics. No Drive or cross-platform match is inferred.
