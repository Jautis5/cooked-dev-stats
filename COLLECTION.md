

## Documented task-tab fallback — 3 November 2026

An unsupported `visibility` option does not prove the authorized browser is
unavailable. Resolve the existing Lost profile from current browser inventory,
then use the documented browser binding, `nameSession`, `browser.tabs.new()`,
and DOM navigation in separate task tabs. Do not activate native windows or
reuse user drafts. This task-tab path was verified on 3 November.

Instagram grids can virtualize older rows. Accumulate unique publication IDs
and preserve each batch's actual observation time while scrolling to the real
end. A count of currently rendered links is not the whole inventory. Do not
advance full-inventory dates from profile followers or known-ID detail reads.

TikTok and YouTube rounded grid values belong in `publicGridViews` alongside
more precise public `views`; keep the raw display and rounding flag. A working
Mac browser pass is still not independent 24/7 collection.
