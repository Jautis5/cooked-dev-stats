How to read these numbers

Views and followers are added platform counts, not unique people. Approximate source values are marked ≈. Missing values remain unknown.

Sources update at different times. Collection checks do not refresh every metric. Each number retains its original observation time.

Collection can be delayed. Full account inventories and restricted metrics may require additional source access.
